# Print a landmark model fit

Shows the model, formula and horizon, then one line per landmark with
its counts and fit status.

## Usage

``` r
# S3 method for class 'landmark_fit'
print(x, ...)
```

## Arguments

- x:

  A `landmark_fit`, as returned by
  [`fit_landmark()`](https://thatoneguy006.github.io/tidylandmark/reference/fit_landmark.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
